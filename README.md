## Project overview

XRepHunter is a browser extension prototype for analyzing public-facing social content and browsing patterns. The project brings feed and profile signals into a dashboard, with an image-assessment path that uses browser-side model tooling.

The work demonstrates product framing, extension architecture, background and content-script coordination, local data handling, model integration, and interface design for information that needs careful interpretation.

## What the prototype explores

- Feed and account activity summaries
- Content quality and AI-image assessment signals
- A dashboard for reviewing activity and analysis results
- Browser extension workflows built with WXT and TypeScript
- Local model and data-processing components

## Review the signals carefully

An automated signal is a prompt for closer review. It does not establish who created a post, whether an account is authentic, or whether content is true. Model results can be incomplete or incorrect and should be considered alongside their visible evidence and limitations.

## Project status

This showcase describes a prototype under development. Build, browser compatibility, model behavior, and current feature availability should be verified against a current release before use. This repository presents project context and selected evidence; it does not distribute the working extension source.
